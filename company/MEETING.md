# اجتماع القادة

الموظفين يشتغلون على مدار الساعة بالشفتات (`SHIFTS.md`). **الاجتماع مو وقت شغل.** هو لتقديم التقارير ورؤية المدير التنفيذي بس.

## متى ينعقد؟
- لما يطلبه المالك: «سوّ اجتماع القادة» في Claude Code، أو من المكتب الافتراضي (قاعة اجتماعات ← «استدعاء قادة المجالات»، أو زر 🚨).
- تلقائياً لما تنعلن **كارثة الفرحة** (`JOY_CRISIS.md`).
- ما فيه اجتماع أسبوعي مجدول.

## مين يحضر؟
**قادة المجالات (13):** `coo`، `chief-inspector`، `auditor-content`، `auditor-tech`، `auditor-design`، `auditor-growth`، `auditor-compliance`،
`head-strategy`، `head-academy`، `joy-index-editor`، `game-lab-head`، `marketing-head`، `hr-head`.
ومعهم `ceo` (المدير التنفيذي) و`ceo-business-manager` (مدير أعماله). أي موظف ثاني يحضر بس إذا انطلب بالاسم.

## الخطوات
الجلسة الرئيسية تنادي الإيجنتات (الإيجنت ما يقدر ينادي إيجنت ثاني).

1. **الافتتاح:** نادِ `ceo-business-manager`. يقرأ `company/office/status.json` و`company/backlog.md` وآخر شغل في `company/work/`،
   ويطلع «الملخص التنفيذي السريع» (3 نقاط: أهم إنجاز، مؤشر الفرحة مقارنة بسين جيم ومخمخ، التارقت المالي) وقائمة المهام المفتوحة.
2. **التقارير (بالتوازي):** نادِ القادة الـ 13 مع بعض. كل واحد **يقرأ** شغل مجاله من الملفات (ما يسوي شغل جديد) ويرجع تقريره بالشكل المكتوب في ملفه.
3. **رؤية المدير التنفيذي:** نادِ `ceo` مع كل التقارير. يقدم:
   - وين وصلنا (بأرقام من التقارير)،
   - الرؤية للفترة الجاية: وين نبي نوصل وليش،
   - أهم 3 أولويات، والقرارات (لكل قرار مسؤول وموعد).
4. **المحضر:** نادِ `ceo-business-manager` يكتب `company/meetings/YYYY-MM-DD-HHMM.md`، ويحدّث `company/decisions.md` و`company/backlog.md`.
5. **الحفظ والإرسال:**
   ```bash
   git add -A company && git commit -m "Leaders meeting YYYY-MM-DD" && git push
   node tools/notify/email_reporter.js "اجتماع القادة YYYY-MM-DD" --file company/meetings/YYYY-MM-DD-HHMM.md
   ```
6. **الرسالة الأخيرة للمالك:** أقل من 15 سطر: الملخص السريع، رؤية المدير التنفيذي بسطرين، القرارات، واللي يحتاج قراره.

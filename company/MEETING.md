# الاجتماع الأسبوعي لشركة الديوانية

هذي خطوات الاجتماع. الجلسة الرئيسية في Claude هي اللي تدير الاجتماع: تنادي الإيجنتات وتجمع كلامهم.
الإيجنت ما يقدر ينادي إيجنت ثاني، عشان كذا الجلسة الرئيسية هي اللي تنادي الكل.

**ممنوع في الاجتماع:** الكتابة في قاعدة البيانات الحية، النشر في السوشال، تشغيل المسح أو الاسترجاع، الدفع على `main`.
الاجتماع يطلع **تقارير وقرارات ومهام**. التنفيذ يصير بعده، واللي يحتاج موافقة يروح للمالك.

**التوفير:** الاجتماع ينادي **رؤساء اللجان بس** (8) مع الأمانة والرئيس التنفيذي. رئيس اللجنة يكتب تقرير لجنته كاملة.
عضو اللجنة ينادى في الاجتماع فقط إذا رئيس لجنته طلبه بالاسم في تقريره، وبحد أقصى 3 أعضاء بالاجتماع كله.

## ① التحضير (بدون إيجنتات)

```bash
cd QD 2>/dev/null || cd /home/user/QD
git fetch origin claude/multi-agent-company-9dst9p && git checkout claude/multi-agent-company-9dst9p && git pull --ff-only
npm ci --no-audit --no-fund
npm test 2>&1 | tail -5
git log --since="7 days ago" --oneline
test -n "$FIREBASE_SERVICE_ACCOUNT" && echo "KEY: yes" || echo "KEY: no"
```

احفظ النتائج في ملاحظة قصيرة تعطيها لكل الإيجنتات تحت اسم «حالة الأسبوع».

## ② أمين السر يفتح الجلسة

نادِ `secretary`: يقرأ `company/backlog.md` و`company/decisions.md` وآخر محضر في `company/meetings/`،
ويطلع قائمة المهام المفتوحة ووش صار فيها.

## ③ تقارير اللجان (بالتوازي، في رسالة وحدة)

نادِ هالرؤساء الثمانية **مع بعض** في نفس الرسالة، وأعط كل واحد «حالة الأسبوع» وقائمة المهام المفتوحة اللي تخص لجنته:

| اللجنة | الإيجنت |
|---|---|
| التنفيذية | `exec-head` |
| التطويرية | `dev-head` |
| الجودة والمحتوى | `quality-head` |
| الإحصائية | `stats-head` |
| المالية | `finance-head` |
| الإعلامية | `media-head` |
| الإدارية | `admin-head` |
| البحث والتطوير | `rnd-head` |

كل واحد يرجع تقريره بالشكل المكتوب في ملفه. `rnd-head` يبحث في GitHub والنت ويكتب «رادار الأسبوع» في `company/research/`. في أول اجتماع بكل شهر نادِ معهم `strategy-advisor`.

## ④ النقاش

إذا فيه تعارض بين لجنتين (مثلاً الإعلامية تبي حملة، والمالية تقول التكلفة عالية) أو رئيس لجنة طلب عضو بالاسم، نادِهم لجولة ثانية قصيرة
على النقطة المختلف عليها بس.

## ④-ب البحث المعمق (اختياري)

إذا `rnd-head` طلب كشاف بالاسم (`oss-scout`، `tech-scout`، `dataset-scout`، `ai-tools-scout`، `security-scout`)، نادِه هنا. ويحسب من حد الـ 3 أعضاء.
أي توصية «اعتمد» من الرادار تنعرض على اللجنة المعنية قبل القرار.

## ⑤ القرارات

نادِ `ceo` وأعطه كل التقارير. يطلع:
- **قرارات الأسبوع** (5 بالكثير)، ولكل قرار مسؤول وموعد.
- **توصيات للمالك**: أي شي يمس الموقع الحي أو فلوس أو نشر علني.
- **المرفوض أو المؤجل** مع السبب بسطر.

## ⑥ المحضر

نادِ `secretary` يكتب:
- `company/meetings/YYYY-MM-DD.md` بالقالب تحت.
- يضيف القرارات الجديدة في `company/decisions.md` والمهام في `company/backlog.md`، ويحدّث حالة المهام القديمة.

بعدها:

```bash
git add company && git commit -m "Weekly meeting YYYY-MM-DD" && git push -u origin claude/multi-agent-company-9dst9p
```

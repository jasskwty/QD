# مولّد أسئلة الديوانية بالذكاء الاصطناعي

أداة تشتغل كل ساعة على GitHub Actions وتضيف **54 سؤال** لموقع [qns.web.app](https://qns.web.app). كل سؤال يمر على **20 مرحلة تحقق**، ولكل سؤال **صورة أو صوت أو مقطع** مع السؤال، وصورة أو مقطع مع الإجابة.

تكتب مباشرة في قاعدة بيانات الموقع (Firestore، مشروع `kwty-2c945`) بنفس الشكل اللي تستخدمه لوحة التحكم، فالموقع نفسه ما يحتاج أي تعديل.

---

## كيف تشتغل

1. **تختار الفئات**: الفئات اللي فيها مستوى فاضي أولاً، بعدها الأقل أسئلة. كل فئة تاخذ 6 أسئلة في التشغيلة (2 لكل مستوى: 200 و400 و600)، يعني 9 فئات في الساعة.
2. **تولّد مرشحين**: ضعف العدد المطلوب، عشان اللي يطيح في التحقق يكون له بديل.
3. **تتحقق على 20 مرحلة**: كل مرحلة طلب مستقل للنموذج بتعليمات خاصة فيه، أو فحص برمجي دقيق. السؤال اللي يطيح في أي مرحلة ينشال، وأي خطأ أو عدم تأكد يعتبر رسوب.
4. **تكتب الناجحين** في الفئة، وتحدّث عدد الأسئلة، وتعيد نشر الفئات للاعبين (`meta/catalog`).

### عن نسبة الخطأ

ما فيه نظام يقدر يضمن نسبة خطأ زي 0.0000000000001%. المعلومات في النت نفسها فيها أخطاء أحياناً، والنماذج تقدر تغلط بنفس الطريقة. اللي تسويه الأداة إنها ما تقبل السؤال إلا إذا اتفقت عليه 20 مرحلة مستقلة، وأي شك يشيله. هذا يخلي الخطأ نادر جداً، بس مو صفر. زر VAR في اللعبة يبقى خط الدفاع الأخير، والبلاغات توصلك في لوحة التحكم.

### الوسائط

الصور والأصوات والمقاطع من [ويكيميديا كومنز](https://commons.wikimedia.org)، وكلها برخص حرة. الملفات تنعرض من روابط ويكيميديا مباشرة، واسم صاحب الملف ورخصته ينحفظون مع السؤال في الحقل `ai.media`.

- الصوت بصيغة mp3 عشان يشتغل على الآيفون.
- المقاطع بصيغة webm، وطولها 3 دقايق بالكثير.
- الأداة **ما تستخدم موسيقى أبداً**، لأن الموقع شال فئات الأغاني. تقدر تعدّل هالقاعدة وغيرها في `src/prompts.js` (المتغير `RULES`).

الفئات اللي ما تنفع بوسائط حرة حقيقية (مثل "الظل" و"أوجد الاختلاف" اللي تحتاج صور معدّلة، أو مسلسلات محمية بحقوق) تتعلّم عليها الأداة بالحقل `aiSkip` وتتخطاها بالمرات الجاية. تقرير كل تشغيلة يبين هالفئات.

## التجهيز (مرة وحدة)

### 0. خل هالريبو خاص (Private)

**Settings ← General ← Danger Zone ← Change visibility ← Private**

سجلات التشغيل والتقارير والنسخة الاحتياطية فيها الأسئلة والإجابات. لو الريبو عام بيقدر أي أحد يشوفها. عشان كذا التشغيلات توقف من نفسها لين يصير الريبو خاص.

### 1. مفتاح Claude API

من [platform.claude.com](https://platform.claude.com) ← API Keys، سو مفتاح جديد. وحط **حد صرف شهري** من Billing.

### 2. مفتاح Firebase

Firebase Console ← مشروع `kwty-2c945` ← ⚙️ Project settings ← **Service accounts** ← **Generate new private key**. بينزل لك ملف JSON.

### 3. حط المفاتيح في GitHub

**Settings ← Secrets and variables ← Actions ← New repository secret**

| الاسم | القيمة |
|---|---|
| `ANTHROPIC_API_KEY` | مفتاح Claude |
| `FIREBASE_SERVICE_ACCOUNT` | محتوى ملف JSON كامل (افتحه وانسخ كل اللي فيه) |
| `WIKIMEDIA_TOKEN` | اختياري: يرفع حد طلبات ويكيميديا. تسويه من [api.wikimedia.org](https://api.wikimedia.org/wiki/Special:AppManagement) ← Create key ← Personal API token |

## الاستخدام

كل هذا من تبويب **Actions** في الريبو.

### أول شي: تجربة

**توليد الأسئلة ← Run workflow**، وخل "تجربة" مفعّلة (هذا الافتراضي)، وحط عدد صغير، مثلاً `6`.

التجربة ما تكتب شي في الموقع. بعد ما تخلص:

- **Summary** في صفحة التشغيلة: كم سؤال نجح، وين انرفضت الأسئلة، والتكلفة.
- **Artifacts**: ملف `report.json` فيه كل الأسئلة وإجاباتها ومصادرها وروابط الوسائط والمرفوضة مع السبب، وملف `questions-import.json` اللي تقدر تستورده بنفسك من لوحة التحكم ← الأسئلة ← استيراد جماعي.

### مسح كل الأسئلة

**مسح كل الأسئلة ← Run workflow** واكتب `DELETE-ALL-QUESTIONS`.

1. ياخذ نسخة احتياطية كاملة أول، وتنحفظ في Artifacts لمدة 90 يوم (وفي Firebase Storage إذا مفعّل).
2. ما يمسح شي إلا إذا انحفظت النسخة.
3. يمسح أسئلة **الفئات العامة بس**. الفئات الخاصة اللي سوّاها اللاعبين ما يمسها.

**تنبيه:** بعد المسح كل الفئات بتكون "قريباً" لين تنملي. بمعدل 54 سؤال بالساعة، كل فئة تاخذ أول 6 أسئلة خلال تقريباً 40 ساعة. وكل ما زادت الأسئلة قلّ التكرار على اللاعبين.

للاسترجاع: **استرجاع الأسئلة من نسخة احتياطية** وحط رقم تشغيلة المسح. الرقم موجود في رابط صفحة التشغيلة: `.../actions/runs/`**`123456789`**.

### تشغيل كل ساعة

**Settings ← Secrets and variables ← Actions ← Variables ← New repository variable**: الاسم `QGEN_ENABLED` والقيمة `true`.

للإيقاف: غيّر القيمة لـ `false`.

## التكلفة

لازم تعرفها قبل ما تفعّل التشغيل كل ساعة.

- **Claude API**: كل سؤال يمر على عشرات الطلبات وبحث في النت. بالنموذج الافتراضي (Claude Opus 5.5) التقدير المبدئي **25 إلى 50 دولار للساعة**، يعني تقريباً **600 إلى 1200 دولار باليوم** لو اشتغلت 24 ساعة. هذا تقدير تقريبي، والرقم الحقيقي يطلع في Summary كل تشغيلة، فجرّب أول وشوف.
- **حد الأمان**: كل تشغيلة توقف إذا وصلت 60 دولار (`QGEN_MAX_USD`).
- **GitHub Actions**: الريبو الخاص ياخذ 2000 دقيقة ببلاش بالشهر، والتشغيل كل ساعة يحتاج أكثر من كذا. من **Settings ← Billing** حط ميزانية لـ Actions، لأن الحد الافتراضي صفر، يعني التشغيلات بتوقف لما تخلص الدقايق المجانية.

لو تبي تقلل التكلفة، غيّر هذي في Variables:

| المتغير | الافتراضي | للتوفير |
|---|---|---|
| `QGEN_MODEL` | `claude-opus-5-5` | `claude-sonnet-5-5` (تقريباً نص السعر) |
| `QGEN_PER_RUN` | `54` | عدد أقل بالساعة |
| `QGEN_EFFORT` | `high` | `medium` |
| `QGEN_MAX_USD` | `60` | حد أقل لكل تشغيلة |

## إعدادات ثانية

| المتغير | الافتراضي | المعنى |
|---|---|---|
| `QGEN_MIN_CONFIDENCE` | `98` | الثقة اللي يحتاجها الحكم النهائي عشان ينشر |
| `QGEN_FINAL_EFFORT` | `max` | مستوى التفكير في المرحلة 20 |
| `QGEN_CONCURRENCY` | `4` | كم فئة تشتغل بنفس الوقت |

الإعدادات كلها في `src/config.js`، وتعليمات النموذج كلها في `src/prompts.js`.

## للمطور

```bash
npm ci
npm test                                   # اختبارات بدون أي طلبات مدفوعة
QGEN_DRY_RUN=1 QGEN_CATEGORIES="عواصم الدول" ANTHROPIC_API_KEY=... node src/generate.js   # تجربة محلية بدون Firebase
```

الحقول اللي تنضاف لكل سؤال، واللعبة تتجاهلها: `ai.run` و`ai.stages` و`ai.confidence` و`ai.alts` و`ai.sources` و`ai.media`.

الحقول اللي تنضاف لكل فئة: `aiAt` و`aiFails` و`aiSkip`. لو تبي ترجع فئة متخطاة، امسح حقل `aiSkip` من Firestore، أو شغّلها بالاسم من خانة "فئات محددة".

# مولّد أسئلة الديوانية (مجاني على اشتراكك في Claude)

مهمة مجدولة في Claude (Routine) تضيف أسئلة جديدة لموقع [qns.web.app](https://qns.web.app) كل كم ساعة:

- كل سؤال يمر على **20 مرحلة تحقق** قبل ما ينضاف.
- كل سؤال له **صورة أو صوت أو مقطع**، وكل إجابة لها صورة أو مقطع.
- ما تحتاج مفتاح API ولا تدفع شي زيادة، لأنها تشتغل على اشتراكك الحالي في Claude.

الأسئلة تنكتب مباشرة في قاعدة بيانات الموقع (Firestore، مشروع `kwty-2c945`) بنفس الشكل اللي تستخدمه لوحة التحكم، فالموقع نفسه ما يحتاج أي تعديل.

## أسئلة بالجملة من ويكي داتا (مجاني وسريع)

أداة ثانية تبني **آلاف الأسئلة دفعة وحدة** من [ويكي داتا](https://www.wikidata.org)، قاعدة المعلومات المجانية اللي تعتمد عليها ويكيبيديا. أمثلة:

- «ما عاصمة …؟»
- «لأي دولة هذا العلم؟»
- «في أي دولة يقع …؟»
- «ما اسم هذا الحيوان؟» مع صورته، و«ما الحيوان صاحب هذا الصوت؟» مع صوته.
- «ما الرمز الكيميائي لـ…؟»
- «من رسم لوحة …؟» و«من مؤلف …؟»
- «في أي مجال حصل … على جائزة نوبل؟»

العدد الحالي والتفاصيل في [`data/bulk-report.md`](data/bulk-report.md).

كل سؤال لازم يعدّي هذي الفحوصات تلقائياً (بدون ذكاء اصطناعي ولا تكلفة):

- المعلومة في ويكي داتا لها جواب واحد بس، وما لها تاريخ انتهاء.
- مقدمة مقالة ويكيبيديا (العربية أو الإنجليزية) تذكر نفس الإجابة. هذا يعتبر مصدر ثاني.
- الأسماء عربية واضحة، وما فيه شي ثاني بنفس الاسم يخلي السؤال محيّر.
- الإجابة مو مكتوبة في السؤال، والسؤال مو مكرر.
- للسؤال وللإجابة صورة أو صوت برخصة حرة من ويكيميديا كومنز.
- الصعوبة حسب شهرة الشي: الأشهر 200، وبعده 400، والأقل شهرة 600.
- أماكن النزاعات السياسية مستبعدة.

**طريقتين للإضافة:**

1. **بنفسك وبدون أي إعداد:** لوحة التحكم ← الأسئلة ← **استيراد جماعي**، واختار ملف من مجلد [`exports/`](exports). فيه ملف لكل فئة.
2. **تلقائي:** بعد ما تضيف مفتاح Firebase، قول لـ Claude «دخّل أسئلة ويكي داتا». الأداة تتخطى الأسئلة اللي انضافت قبل، وتحفظ اسم صاحب كل صورة ورخصتها مع السؤال. وتضيف 15,000 سؤال باليوم بالكثير عشان تبقى ضمن حد Firebase المجاني، وتكمل الباقي باليوم اللي بعده.

## الكمية

كل تشغيلة تضيف **لين 12 سؤال** (فئتين، 6 لكل فئة: 2 من كل مستوى 200 و400 و600)، والتشغيل كل 4 ساعات. يعني تقريباً **لين 72 سؤال باليوم**. ما يوصل 54 بالساعة، لأن كل تشغيلة تاكل من حد استخدامك في Claude.

لو تبي أكثر أو أقل، قول لـ Claude يغيّر الجدول أو العدد.

## كيف تشتغل

جلسة Claude جديدة تبدأ من نفسها وتتبع الخطوات في [`ROUTINE.md`](ROUTINE.md)، وتستخدم الأداة `tools/q.js`:

1. **تختار الفئات** اللي تحتاج أسئلة أكثر شي: الفئات اللي فيها مستوى فاضي أول.
2. **تكتب مرشحين**: ضعف العدد المطلوب.
3. **تمررهم على 20 مرحلة.** الأداة نفسها تمنع تخطي أي مرحلة أو تغيير ترتيبها، وأي سؤال يطيح في مرحلة وحدة ينشال.
4. **تكتب الناجحين في الموقع** وتحدّث عدد الأسئلة للاعبين. قبل الكتابة تعيد فحص كل شي مرة أخيرة.

| 11 | الرخصة حرة والرابط يشتغل | الأداة |

**عن نسبة الخطأ:** ما فيه نظام يضمن 0.0000000000001%. المراحل الـ 20 تخلي الخطأ نادر جداً بس مو صفر، وزر VAR في اللعبة يبقى آخر حماية.

**الوسائط:** كلها من [ويكيميديا كومنز](https://commons.wikimedia.org) وبرخص حرة. الصوت بصيغة mp3 عشان يشتغل على الآيفون، والمقاطع بصيغة webm. **ما فيه موسيقى أبداً**، لأنك شلت فئات الأغاني.

**الفئات اللي ما تنفع** بوسائط حرة حقيقية، مثل "الظل" و"أوجد الاختلاف" أو المسلسلات المحمية بحقوق، تنعلّم وتتخطاها بالمرات الجاية.

## التجهيز: خطوة وحدة

1. Firebase Console ← مشروع `kwty-2c945` ← ⚙️ Project settings ← **Service accounts** ← **Generate new private key**. بينزل لك ملف JSON.
2. في Claude، من قائمة البيئة (cloud environment) فوق في عنوان الجلسة ← **Edit**، ضيف متغير بيئة اسمه `FIREBASE_SERVICE_ACCOUNT`، وقيمته محتوى ملف JSON كامل.

**لا تلصق المفتاح في المحادثة أبداً.** وخل الملف عندك بمكان آمن.

## التحكم

قول لـ Claude:

- «وقّف مهمة الأسئلة» أو «رجّعها».
- «خلها كل ساعتين» أو «خل كل تشغيلة 6 أسئلة».
- «شغّلها الحين».

نتيجة آخر تشغيلة تنحفظ في Firestore في `meta/aigen`.

## مسح كل الأسئلة

الأداة **ما تمسح شي**. تضيف أسئلة بس.

لو مسحت كل الأسئلة الحين، الموقع بيظل أغلبه فاضي **تقريباً شهر**: الفئات كثيرة (حوالي 360)، وكل فئة تحتاج 6 أسئلة على الأقل، وبمعدل 72 سؤال باليوم ياخذ الموضوع وقت طويل.

إذا تبي تمسح، فيه أداة تمسح بعد نسخة احتياطية كاملة، ولها زر استرجاع: الملف `.github/workflows/wipe.yml`. بس تحتاج:

- الريبو يكون خاص (Private)، لأن النسخة الاحتياطية فيها كل الأسئلة.
- السر `FIREBASE_SERVICE_ACCOUNT` في GitHub ← Settings ← Secrets and variables ← Actions.

بعدها من **Actions ← مسح كل الأسئلة** تكتب `DELETE-ALL-QUESTIONS`. المسح يشيل أسئلة الفئات العامة بس، وما يمس فئات اللاعبين الخاصة.

## للمطوّر

```bash
npm ci
npm test                      # اختبارات بدون أي اتصال بقاعدة البيانات
node tools/q.js               # الأوامر
```

تقدر تجرّب بدون قاعدة البيانات:

```bash
node tools/q.js next --categories "عواصم الدول"
node tools/q.js write --dry
```

الحقول اللي تنضاف لكل سؤال، واللعبة تتجاهلها: `ai.run` و`ai.stages` و`ai.confidence` و`ai.alts` و`ai.sources` و`ai.media` (المصدر والرخصة وصاحب الملف).

الحقول اللي تنضاف لكل فئة: `aiAt` و`aiFails` و`aiSkip`. لو تبي ترجع فئة متخطاة، امسح حقل `aiSkip` منها في Firestore.
